## 1. How the real model is wired

`src/llm.js` now supports a custom auth header/scheme:

```text
LLM_PROVIDER=openai
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-flash
LLM_AUTH_HEADER=x-dsh-auth-token
LLM_AUTH_SCHEME=
```

`scripts/start-with-dsh-llm.mjs` reads the DeepSeek account token already stored by local DSH, keeps it in process memory, and imports the app server. It prints only:

```text
RelayDesk MVP (real LLM) running at http://127.0.0.1:3030 (openai/deepseek-flash)
```

The token is not in `.env`, source, logs, tests, or the archive.

## 2. Natural response behavior

The system prompt now asks for a warm human support tone, 1–3 conversational sentences, exact facts, no source-copying, no internal evidence references, and no invented policy.

Examples from the real run:

- Text (AC-02): `您好，今天我们是09:00开门，21:00关门，每天都是这个营业时间哦。`
- Voice hours (AC-04): `您好！我们每天都是早上9点开门，晚上9点关门，欢迎您随时过来～`
- Voice package: `您好！标准快递一般是 3-5 个工作日送达，您可以按这个时间来留意一下～...`
- High-risk voice still bypasses the model and returns the deterministic safe escalation template.

Voice responses keep the UI contract `soothing → confirm → answer`, but the answer segment is now generated by the real model. A model failure still falls back to the extractive path.

- 20 real voice samples still run; threshold remains 30s; p95 was 1089 ms.
- Added `reply.model` and grounding assertions.

## 5. Boundaries

1. The DSH account token is a local development credential; production should use a dedicated provider key in a secret manager.
2. DeepSeek wording varies by run; tests assert semantic facts and naturalness instead of one exact sentence, while safety/high-risk assertions remain strict.
3. High-risk messages intentionally do not call the model; they use the safe escalation template.
4. Model latency/availability remains an external dependency; the gateway has retry, circuit breaker and extractive fallback.
5. `node:sqlite` remains single-node and experimental.
