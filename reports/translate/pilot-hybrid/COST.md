| 指标 | 数值 |

## 成本假设

- DeepSeek V3.2 官方价：**$0.28/百万输入、$0.42/百万输出**，汇率 7.2 → **¥2.016/百万输入、¥3.024/百万输出**
- 电费：**¥0.6/kWh**；Q5 整机 0.5 kW，Q6 整机 0.55 kW
- LanguageTool：本地 Java 规则引擎，**0 API 费用**
- 不含人工审核、机器折旧、带宽

## 三条路线对比（每 1,000 张卡）

| 路线 | 质量均分（5 卡） | 本地耗时 | 云端 Token | 直接成本/千卡 | 是否过 4.5 |
|---|---|---|---|---|---|
| **A：Q5 + LanguageTool** | **3.6 / 5** | 9.8 h | 0 | **¥2.95**（电费） | ❌ |
| **B：A + 云端语法后编辑** | **4.2 / 5** | 9.8 h + 4.9 h 云端 | 输入 0.59M / 输出 3.74M | **¥15.45**（电费 ¥2.95 + API ¥12.50） | ❌ |
| C：Q6 本地直出 | 未测 | 不可行 | 0 | 无法在当前机器运行 | 未知 |

> B 若对每张卡都做母语评分（QA），额外 ¥12.74/千卡；按 10% 抽检则 ¥1.27/千卡。

## C 路线（Q6）实测结论

调用 `qwen3.8-35b-a3b@q6_k` 直接失败：

```
Failed to load model "qwen3.8-35b-a3b@q6_k".
Error: Model loading was stopped due to insufficient system resources.
Under the current settings, this model requires approximately 28.89 GB of memory...
```

- Q6_K 权重约 **28.9 GB**，当前机器无法加载；
- 即使升级到 48GB 显存，按 Q5 吞吐 × 0.85 估算约 **37.6 tok/s（41.7 s/卡）**，电费约 **¥3.82/千卡**，另需显卡 CapEx；
- Q6 对波兰语语法的实际提升未经验证，不能假设一定过 4.5。

## 商业结论

1. **A 路线最便宜（¥2.95/千卡），但 3.6 分不能商用**；只能用于低风险内部参考。
2. **B 路线质量最高（4.2），但仍未过 4.5**；剩余问题已不是语法，而是语义/术语（`utylizacja`、`logistyka zwrotna`、`category` 类型被改）与增译，语法后编辑解决不了。
3. **C 路线当前硬件不可行**，且质量未验证；不建议为未验证的 Q6 先投入显卡。
4. **最高性价比的下一步**：在 B 之上加一次“语义对齐后编辑”（专门检查增译、术语、类型/结构），只对 3.5–4.4 分卡触发；按 B 的成本估算，每千卡仍可控制在 ¥20 内，且不依赖 Q6。
