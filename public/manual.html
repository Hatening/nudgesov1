使用指南

不用记术语。每一步都很简单，照下面的图和按钮做就行。

1. 打开网站，登录

用注册时填的邮箱和密码登录。登录后第一页会告诉你今天有几件事要处理，照着点按钮去做就好。

现在去做 / Do it now

2. 把店铺资料传进来

把产品说明、发货时间、退换货规则，拖进上传页面就行。系统会自动读懂，不需要你做别的。

如果传的是照片或扫描件，系统会先认出里面的字，弹出来请你核对一遍——看看有没有认错，改好了点确认。

3. 告诉我们你开的是什么店

在「设置」里填上店名、主要卖什么、做哪些国家的生意。填好以后，系统回答客户会更像你店里的人。

例子：店名 Northstar Goods，卖家居和宠物用品，主要做美国和欧洲。

现在去做 / Do it now

4. 拿不准，就问系统

直接打字问就行，比如：「我家退货率有点高，该怎么办？」系统会结合你店里的情况给你建议。

现在去做 / Do it now

5. 看客户发给你的消息

「客户消息」里每一条都能看到客户说了什么，系统会帮你写好回答。退款、投诉这类要紧的事，会单独放到「需要你处理的问题」里。

现在去看客户消息 / Do it now

6. 确认资料才算数

传上来的资料一开始是「待确认」状态。你确认以后，它才会真的用来回答客户。看到「待确认」标签，点一下「确认加入」就好。

现在去确认资料 / Do it now

7. 常见问题

照片里有认错的字？在核对框里直接改，再点确认。传了资料客户却还没被回答到？看看那条资料是不是还挂着「待确认」，点一下确认就好。

去人工队列看看 / Do it now

8. 资料和隐私

你传的资料只用来回答你自己店的客户。不要传身份证号、银行卡号这类敏感信息。平台规则记得写清楚是哪一条、什么时候开始生效。
